# Proyecto Huerto Hogar
 Este proyecto, hecho en html, javascript y css, es para proponer una solucion frente a una tienda de alimentacion saludable. Para este proyecto nos ayudamos con bootstrap para hacer el diseño de la pagina web y tambien usamos font awesome para implementar iconos a la pagina.
# Partes de la propuesta

Inicio:Aca se muestra el inicio de la pagina web, donde podremos ver los productos de la tienda 

Registro de sesion:Para poder registrarse a la pagina con un usuario

Blog:En este apartado creamos un blog de noticias o informacion respecto a la alimentacion saludable y la sustentabilidad, esta dividida en 2 partes para que sea mas ordenado

Nosotros: Informacion sobre la tienda y su ideologia de negocio

Contacto:Un formulario de contacto para que cualquier cliente se pueda contactar con la tienda directamente por medio de correo electronico

Productos:Muestra de productos frescos de la tienda para su compra

Pagina de Administracion:Administrar la pagina, como manejar el stock de los productos, etc

Perfil:Perfil de usuario

Carrito:El carrito de compra de los productos


# Validaciones

Nuestras validaciones en los apartados del inicio de sesion, asi como en el formulario de contacto los hicimos en javascript, validaciones como formato de email correcto, nombre valido, etc
